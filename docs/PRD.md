# VIBE — PRD (Product Requirements Document)

Версия: 1.0
Статус: Approved
Дата: 06.08.2026

---

## 1. Миссия

Vibe — коммуникационная платформа нового поколения: мессенджер + бизнес + экономика креаторов, защищённая сквозным постквантовым шифрованием. Создана с нулевым бюджетом — и это часть её истории.

## 2. Видение одной фразой

«Телеграм, который нельзя вскрыть даже квантовым компьютером, где у каждого магазина свой офис, у каждого креатора — лавка стикеров, у каждого человека — репутация, и всё пересыпано искрами».

## 3. Стратегия

- **Wedge**: личный мессенджер с PQ-E2EE → аудитория
- **Деньги**: B2B-подписки (990/2990/9990 ₽) + 30% маркетплейс + white-label + +Vibe (299 ₽)
- **Рынок**: РФ. RuStore — первый канал публикации (бесплатно)
- **История**: продукт с нулевым бюджетом против гигантов

## 4. Бренд

- Имя: **Vibe** (зафиксировано владельцем). До релиза: проверка коллизий в RuStore/Play, заявка на товарный знак
- Маскот: **Вайбик** — чёрный круглый пузырёк с неоновой обводкой и милыми глазами
- Эстетика: тёмный неон, фиолетовый `#8B5CF6`, «вывеска ночного клуба»
- Валюта: **Искры ✦** (не «звёзды»)

## 5. Функциональные требования по релизам

### v1.0 — Ядро (личный мессенджер)
- Онбординг: 3 экрана («PQ-защита», «бизнес в чатах», «экономика»), создание профиля (имя + эмодзи-аватарка), объяснение разрешений, конфетти
- Чаты: список с папками (все/личные/группы/каналы/бизнес), свайпы (вправо — прочитано/архив, влево — DND), мультивыбор, архив, скрытые чаты (биометрия)
- Сториз-кружки сверху списка чатов
- Диалог: текст, реакции (двойной тап = сердце с искрами), статусы, голосовые с волной, фото/видео, видеокружки, стикеры Вайбика, отмена отправки 5 сек, отложенные сообщения, перевод, пересылка, цитаты, закреп
- Щит 🛡 PQ-защиты у каждого сообщения + панель доверия (алгоритмы, ключи, журнал событий)
- Push-уведомления (FCM), офлайн-очередь
- Кастомизация: светлая/тёмная/авто, скругление пузырей, плотность списка
- Базовая модерация (жалобы + фильтры)
- **PQ-E2EE**: ML-KEM-768 + X25519 (гибрид), Double Ratchet, ML-DSA подписи, ChaCha20-Poly1305, safety numbers

### v2.0 — Aurion + Звонки

### v3.0 — Бизнес

- Пилоты с живыми компаниями

### v4.0 — Экономика

### v5.0 — Масштаб

## 8. Криптография (спецификация)

- Идентичность: ML-DSA-65 ключ на устройстве
- Prekeys: ML-KEM-768 + X25519 (гибридные) — публикуются на сервер
- Рукопожатие: PQXDH (по опубликованной конструкции Signal, с ML-KEM вместо Kyber-512)
- Сообщения: Double Ratchet, ключ на каждое сообщение, HKDF-SHA512
- Шифр: ChaCha20-Poly1305
- Подпись: ML-DSA-65 (вместо WOTS+ — stateless, стандарт NIST)
- Проверка: safety numbers, сравниваемые вслух
- Принцип «собери сейчас — расшифруй потом» закрыт: PQ-гибрид с первого дня
- Крипто-ядро: открытый код + тест-векторы; платный аудит при появлении выручки

## 10. Правила работы

1. Одна фича = анализ → спецификация → код → тест → утверждение владельцем
2. Одна фича = один коммит; каждая фаза = рабочий билд на устройстве
3. Документация обновляется вместе с кодом
4. Один инструмент (opencode), одна линия кода
5. Качество прежде скорости: ни одна фича не стартует, пока не готов предыдущий релиз
