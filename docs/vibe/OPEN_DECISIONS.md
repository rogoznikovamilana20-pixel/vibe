# OPEN DECISIONS — Vibe (Phase 2)

> Открытые архитектурные вопросы с рекомендациями. Решения фиксируются здесь и переносятся в PLAN.md.

## D1. State management

**Решение (11.08.2026, решено мастером по мандату «реши сам и реализуй под ключ»)**: остаться на нативных `ValueNotifier`/`Stream` + контроллеры-классы (`ChatController`, `ChatListController`). Ноль новых зависимостей; контроллеры тестируемые; подключение провайдера позже — обёртка, не переписка.

## D2. Подход к декомпозиции героев

**Решение (11.08.2026)**: пошагово (REFACTORING_PLAN): сначала чистые экстракции виджетов (Фаза A), потом контроллеры (Фаза B), потом фичи (Фаза C) — каждый шаг компилируется и проверяется.

## D3. Порядок: бэкенд-фиксы vs декомпозиция

**Решение (11.08.2026)**: сначала декомпозиция (Фаза A/B), т.к. фиксы unread/read_by лягут в `ChatController`; до него они писались бы в монолит.

## D4. Реакции (PRD 2.7.3 / «React Custom»)

**Решение (11.08.2026, решено мастером по мандату «реши сам что будет красивее»)**: классические emoji-реакции с кастомной эстетикой Vibe: плавающая панель из 6 быстрых реакций (❤️ 👍 😆 😮 😢 🔥) + кнопка «+» для полного emoji-пикера; бейдж на сообщении с градиентной обводкой и счётчиком. Основание: msgEvents уже несёт reactions (инфраструктура готова), React Custom накладка — фирменный паттерн PRD §1.7, будет отдельной фичей после стабилизации.

## D5. Read receipts в группах (PRD 2.7.8.3–4)

**Решение (11.08.2026)**: после — дешёвый scope: mark_read + batched-отправка уже запланированы миграцией `migrate_v1_7_0_read_state.sql`; read_by — следующий слой (Фаза C+).

## D6. Медиа-галерея и фон чата (PRD 2.7.5–2.7.6)

**Решение (11.08.2026)**: фон чата — простая фича с высокой видимостью (параметр как продукт) — после Фаз A/B/C; галерея — после реакций.

## D7. Aurion

**Решение (11.08.2026)**: интеграция после стабилизации чата (Фазы A/B/C). `AurionScreen` до этого не меняется.

## D8. Локализация

**Решение (11.08.2026)**: точечно при прикосновении к файлу (в рамках других фаз) — отдельная фаза без пользовательской ценности не делается.
