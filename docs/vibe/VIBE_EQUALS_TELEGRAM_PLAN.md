# VIBE = TELEGRAM — План достижения 1:1 паритета

> Цель: визуал, техническая часть, механика взаимодействия пользователя с интерфейсом — 1:1 как в Telegram,
> но с сохранением уникальных фич Vibe (Aurion, stories, папки, виджет навигации).
>
> Правило: Telegram — эталон UX-паттернов. Vibe — свой продукт. Код не копировать, решения адаптировать.

## КОМПАКТНЫЙ ИНТЕРФЕЙС (P0, отдельная задача)

> В Telegram на экране чатов видно 7–9 чатов. В Vibe сейчас 4–5. Нужно уплотнить.

### Текущие проблемы
- Высота `ChatListItem` слишком большая (аватар 56px + отступы)
- Stories-лента занимает лишнее место
- Заголовок «Чаты» слишком высокий
- Архив/Saved占用 место даже когда пусто

### Целевые размеры (как в Telegram)
| Элемент | Telegram | Vibe (сейчас) | Цель |
|---------|----------|---------------|------|
| Высота чата | 72px | ~90px | 72px |
| Аватар | 54px | 56px | 54px |
| Отступ между чатами | 1px | 2px | 1px |
| Шрифт имени | 16px bold | 16px bold | 16px bold |
| Шрифт превью | 14px | 14px | 14px |
| Время | 12px | 12px | 12px |
| Stories-лента | 60px высота | 80px | 60px |
| Заголовок «Чаты» | 56px | 80px | 56px |

### Что сделать
- [ ] Уменьшить `ChatListItem` height до 72px
- [ ] Уменьшить аватар до 54px
- [ ] Уменьшить отступы в stories-ленте
- [ ] Сделать заголовок «Чаты» компактнее
- [ ] Убрать лишние SizedBox между элементами
- [ ] Pinned section: компактный заголовок
- [ ] Archive/Saved: только строка, без лишнего пространства

### Проверка
- На экране 1080p (6.5") видно 7–9 чатов без скролла
- На экране 720p (5.5") видно 6–7 чатов
- Все элементы читаемы, ничего не обрезается
